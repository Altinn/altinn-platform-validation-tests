# Access Management, end user APIs

What a logged in person or organization can see and do about their own access.

- `authorized-parties` asserts that a delegating party shows up in the receiver's aktørliste.
- `connections` reads connections and access packages in both directions.
- `client-delegations` reads the client list of a user or system user.
- `request` runs the "be om tilgang" flow end to end.
