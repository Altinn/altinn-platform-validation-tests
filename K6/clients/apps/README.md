# Swagger docs
https://ttd.apps.tt02.altinn.no/ttd/brukermonster-test-app/swagger/index.html?urls.primaryName=End+user+app+API+for+ttd%2Fbrukermonster-test-app

Every app has its own swagger. The clients follow the end user one for ttd/brukermonster-test-app,
`/{org}/{app}/v1/customOpenapi.json`, which documents the API the apps offer their users. The
"Altinn App API" next to it lists the controllers in app-lib-dotnet without describing them.

The swagger has no operationIds, so the methods are named after the summaries.
